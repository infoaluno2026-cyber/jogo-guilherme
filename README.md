# Fire Ice

Jogo web da aventura de Lonpi, criado para o projeto dos alunos Guilherme Silva Lima, Isaque Gabriel Souza Porcino e Felipe Gabriel Rodrigues da Silva.

## Como jogar

Abra `index.html` no navegador. Na arena, use **WASD** ou as **setas** para mover Lonpi e **Espaço** para lançar bolas de fogo contra Winter.

## Publicar no GitHub Pages

Este projeto já está pronto para GitHub Pages: ele é um site estático com `index.html`, `style.css`, `game.js` e assets locais, então não exige build nem dependências.

1. Envie esta pasta para um repositório no GitHub.
2. Abra **Settings > Pages**.
3. Em **Build and deployment**, selecione **Deploy from a branch**.
4. Escolha a branch `main` e a pasta `/ (root)`.
5. Salve. O GitHub Pages fornecerá um endereço do tipo `https://seu-usuario.github.io/nome-do-repositorio/`.
6. Opcional: mantenha o arquivo `.nojekyll` na raiz para evitar que o GitHub trate arquivos especiais como páginas Jekyll.

O jogo funciona diretamente no GitHub Pages com HTTPS.
